# Maquette p.56 — diplôme et clôture réunis

`mockups/p56_diplome_cloture_100pct_NON_PRODUCTION.pdf` teste le partage vertical d’une page Letter entre :

1. titre de félicitation bilingue ;
2. ligne de prénom et zone de sourire ;
3. séparation claire ;
4. formule finale bilingue ;
5. réserve explicitement vide pour une future illustration approuvée.

Aucun visuel Pip, pictogramme ou asset de production n’est utilisé. La zone réservée ne constitue pas une demande de création d’asset. La maquette est un test d’espace seulement ; son texte et sa composition restent soumis à validation humaine bilingue et pédagogique.
