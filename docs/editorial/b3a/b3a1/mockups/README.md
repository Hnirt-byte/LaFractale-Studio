# Maquettes de corrigés à taille réelle — NON PRODUCTION

Les deux PDF sont des tests dimensionnels synthétiques. Ils ne contiennent ni activité définitive, ni réponse validée, ni illustration de production.

- Format : Letter 8,5 × 11 in / 612 × 792 pt.
- Toute page porte le bandeau `NON PRODUCTION`.
- Une jauge de 10 mm permet de vérifier l’impression à taille réelle.
- Imprimer avec « taille réelle », sans adaptation à la page.

Les limites et la comparaison détaillée sont consignées dans `../02_comparaison_options_corriges.md`.
